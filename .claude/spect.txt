# PREMIUM VIETNAMESE WEDDING PLATFORM

## Template Marketplace + Cinematic Wedding Builder

Build a production-quality Vietnamese wedding website platform.

Tech:

* Next.js latest stable
* TypeScript strict
* React
* PostgreSQL
* Prisma
* S3-compatible object storage
* GSAP
* ScrollTrigger
* Lenis
* Three.js
* React Three Fiber
* Drei
* Framer Motion
* Tailwind CSS
* Zod
* Zustand
* dnd-kit

The product should compete with Vietnamese wedding invitation platforms, but the visual quality should be significantly more cinematic and premium.

Reference:

https://zenlove.me/template-preview/thiep-cuoi-11-pre

Do NOT clone ZenLove.

Use it only as UX/reference for:

* Vietnamese wedding information architecture
* template preview
* wedding content
* event information
* family information
* RSVP
* map
* QR
* music
* sharing

The product must have its own visual identity.
